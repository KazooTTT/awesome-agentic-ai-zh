## 🧭 第一次來先走這裡

如果你是來學 AI Agent，先回到[主路線](../README.md)，從 [Stage 0](../stages/00-foundations.md) 開始。遇到名詞再查 Glossary；想親手做時再開 Cookbook。你不需要先讀完整個 `resources/`。

<details markdown="1">
<summary>展開：這些頁面為什麼分開</summary>

- **Glossary** 回答「這個詞是什麼」。
- **Stage** 回答「這個觀念怎麼用」。
- **Cookbook** 回答「我要按哪些步驟做出來」。
- **Schema cheatsheet** 只處理工具介面的設計規則。
- **Catalog** 幫你找候選工具，不替你決定是否安全安裝。

同一個主題可能互相連結，但每頁只負責一種讀者問題。

</details>

<details markdown="1">
<summary>展開：三語與新增 reference 的維護規則</summary>

- zh-TW 是 canonical；英語與簡中必須保留相同事實、URL、狀態與限制。
- 新頁不能只是把既有章節重寫一次；它要解決主線不適合承擔的查詢或實作問題。
- 新 reference 應能服務多個 Stage 或角色路線。只服務單一章節的補充，優先放回該章。
- 版本、價格、可用性、授權與服務狀態要用官方來源查證；找不到時明寫未知，不猜答案。
- 編輯評分可以保留；GitHub stars、固定總數和行數不拿來當品質證據。

</details>
