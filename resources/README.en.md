## 🧭 Start here on your first visit

Pick the row above that matches your task. If you are learning Agents from scratch, start with the main [README](../README.en.md) and [Stage 0](../stages/00-foundations.en.md), then return here when a term or tool needs clarification.

<details markdown="1">
<summary>Expand: why these pages are separate</summary>

- **glossary** is a quick lookup; the stage text gives the learning path; the cookbook is for trying a workflow.
- **schema-design-cheatsheet** explains schema rules, while cookbook 2 explains how to run an MCP server.
- **cli-agents-guide** compares product roles; the catalog groups plug-in tools by task.
- **Hello-Agents** is a deep Chinese-language course. This repo takes a roadmap + curated catalog + hands-on recipe angle and does not replace it.

</details>

<details markdown="1">
<summary>Expand: trilingual and new-reference maintenance rules</summary>

- zh-TW is canonical; English and Simplified Chinese must preserve the same facts, URLs, status, and limits.
- A new page must solve a lookup or implementation problem the main path should not carry, not merely rewrite an existing chapter.
- A new reference should serve more than one Stage or role path. If it only supplements one chapter, keep it in that chapter.
- Verify versions, prices, availability, licenses, and service status with official sources. If the answer is unknown, say so instead of guessing.
- Editorial ratings may stay; GitHub stars, fixed totals, and line counts are not quality evidence.

</details>
